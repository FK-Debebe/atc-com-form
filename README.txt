FILES

- 404.html    : fallback copy

GITHUB PAGES SETUP
1. Create or open the Pilot Vibes tools repository.
2. Create a folder named:
      atc-com-form
3. Upload index.html into that folder.
4. If using one repository for all Pilot Vibes tools, the page will normally be:
      https://YOUR-USERNAME.github.io/REPOSITORY-NAME/atc-com-form/
5. Later, with a custom domain such as pilotvibes.fwdskillzone.com:
      https://pilotvibes.fwdskillzone.com/atc-com-form/

The form is static and does not require Google Apps Script.
CLEAR FORM runs in the browser.
PRINT FORM uses the browser print dialog.
